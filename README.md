# Página de redes sociais

Projeto de estudo com uma página inicial que reúne meus links de redes sociais (Instagram, Facebook e GitHub), cada um com sua própria página estilizada.

🔗 **No ar:** [redesocial-woad.vercel.app](https://redesocial-woad.vercel.app)

## Tecnologias

HTML5, CSS3, deploy na Vercel.

## Estrutura

```
projeto.social/
  index.html       # Entrada
  home.html        # Página inicial
  instagram.html
  facebook.html
  github.html
  estilos/         # CSS
```
